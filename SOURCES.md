## What to study / 读什么

### openai/codex

Rust runtime 与 app-server 协议分离；审批、工具执行、rollout 各有边界。参考完整编码产品，不把内部 API 当稳定跨宿主协议。

Lightweight coding agent that runs in your terminal

### anthropics/claude-code

公开仓库主要用于文档、插件与示例，不等于完整产品运行时开源；根许可证指向商业条款。SDK 和产品许可分开判断。

Claude Code is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows - all through natural language commands.

### bytedance/trae-agent

Python 研究友好循环、工具执行器和 trajectory；适合消融及自研实验，不代表 TRAE IDE 整体源码。

Trae Agent is an LLM-based agent for general purpose software engineering tasks.

### lencx/ChatGPT

Tauri webview/IPC 桌面封装；v2-dev 无根许可证文件，不能默认允许复制；不提供通用可靠 agent 平台。

❄️ ChatGPT Desktop Application (Mac, Windows and Linux)

### anomalyco/opencode

按 session key 串行协调、不同 key 并发；interrupt 接受与 cleanup 完成不同，wake 防丢唤醒。与同名 Go 归档仓库不同。

The open source coding agent.

### google-gemini/gemini-cli

工具 scheduler 显式跟踪验证、审批、执行和终态；sandbox 与 checkpoint 分层，适合观察可取消工具队列。

An open-source AI agent that brings the power of Gemini directly into your terminal.

### earendil-works/pi

AgentMessage 到提供方消息的转换在调用边界；steering/followup 和扩展可组合，小核心不自动提供平台持久调度。

AI agent toolkit: unified LLM API, agent loop, TUI, coding agent CLI

### Aider-AI/aider

RepoMap 用代码 tag/缓存与 token 预算选择上下文；编辑和 Git 流程适合编码助手，不等同通用服务编排。

aider is AI pair programming in your terminal

### aaif-goose/goose

持久会话上的 re-entrant operation pipeline；整批工具请求须全部配对，单个 tool result 不能代表批次结束。

an open source, extensible AI agent that goes beyond code suggestions - install, execute, edit, and test with any LLM

### LibreChat-AI/LibreChat

产品层多 agent、认证和持久 checkpoint；graph namespace 与存储 owner scope 有区别，租户/代际归属需显式保存。

Enhanced ChatGPT Clone: Features Agents, MCP, Skills, DeepSeek, Anthropic, AWS, OpenAI, Responses API, Azure, Groq, o1, GPT-5, Mistral, OpenRouter, Vertex AI, Gemini, Artifacts, AI model switching, message search, Code Interpreter, langchain, DALL-E-3, OpenAPI Actions, Functions, Secure Multi-User Auth, Presets, open-source for self-hosting. Active

### CherryHQ/cherry-studio

renderer IPC、主进程流管理、持久化分层；主进程为审批单写者，attach/detach/abort 语义区分。许可 AGPL 需按复用组件检查。

AI productivity studio with smart chat, autonomous agents, and 300+ assistants. Unified access to frontier LLMs

### cline/cline

SDK 核心将 host、会话、待决 prompt、automation 服务装配到多种客户端，复用时查 runtime capability 和产品版本。

Autonomous coding agent as an SDK, IDE extension, or CLI assistant.

### lobehub/lobehub

Agent 与执行 engine 分离；executor 可覆盖、human interaction 与 group orchestration 明确建模。社区许可证不能当普通 MIT。

🤯 LobeHub is your Chief Agent Operator, organizing your agents into 7×24 operations by hiring, scheduling, and reporting on your entire AI team.

### open-webui/open-webui

多模型/检索/工具/权限的产品集成，中间件处理消息和工具；前端产品并不替代安全执行环境。使用其专有根许可。

User-friendly AI Interface (Supports Ollama, OpenAI API, ...)

### anthropics/skills

技能流程、资源与可验收产物；MCP builder 强调契约和评估。docx/pdf/pptx/xlsx 为 source-available，按组件许可。

Public repository for Agent Skills

### anthropics/claude-plugins-official

插件装配 skills/commands/agents/hooks/MCP；名称 slug 不宜随意更改；市场收录不代表权限与兼容性已验证。

Official, Anthropic-managed directory of high quality Claude Code Plugins.

### openai/plugins

下载技能和 MCP 的最大来源；声明式装配业务知识与执行能力，云端连接定义不等于 SaaS 实现源码。

OpenAI Plugins

### openai/skills

标准技能包与分场景资源；保留工具/运行时要求，跨宿主按实际能力映射，不能仅替换产品名。

Skills Catalog for Codex

### obra/superpowers

分阶段计划、调试、验证、评审可按需吸收；不继承强制全局启动规则或隐式扩大派发/审批。

An agentic skills framework & software development methodology that works.

### muratcankoylan/Agent-Skills-for-Context-Engineering

上下文预算、压缩、长期记忆、评估、harness 与多 agent 隔离；高级 KV/cache 与自改进方法必须确认运行时条件。

A comprehensive collection of Agent Skills for context engineering, multi-agent architectures, and production agent systems. Use when building, optimizing, or debugging agent systems that require effective context management.

### openai/openai-agents-python

Agent/Runner、handoff、session/run state 与工具 guardrails；链首/链尾检查并不覆盖所有副作用，按工具边界控制。

A lightweight, powerful framework for multi-agent workflows

### openai/openai-agents-js

TypeScript runner、approval 与可恢复 RunState；序列化和工具 identity/version 耦合，不能假设与 Python 所有特性对称。

A lightweight, powerful framework for multi-agent workflows and voice agents

### anthropics/claude-agent-sdk-python

包装 Claude CLI；allowed_tools 是 auto-approve，can_use_tool 只处理 ask，PreToolUse 与 tools/disallowed_tools 各有语义。



### OpenHands/software-agent-sdk

Conversation/event store/security/workspace 与 Agent Server；IDLE 非终态，risk 分析与确认策略分离。调度由外部 automation 项目负责。

A clean, modular SDK for building AI agents with OpenHands V1.

### OpenHands/OpenHands

当前快照是 Agent Canvas 前端，消费 SDK/Agent Server，不直接执行动作或提供隔离，automation 是独立服务。

🙌 OpenHands: AI-Driven Development

### OpenHands/OpenHands-CLI

README 声明不再积极维护；可参考 ACP/local/remote runner，但新项目优先核验维护中入口。

Lightweight OpenHands CLI in a binary executable

### modelcontextprotocol/typescript-sdk

main 为 v2 分包；v1 import 路径与协议版本需分别匹配，避免把旧插件示例混用进新 SDK。

The official TypeScript SDK for Model Context Protocol servers and clients

### modelcontextprotocol/servers

七个 reference server 为教学实现；有工具不等于生产安全，roots 不能扩大初始允许范围。

Model Context Protocol Servers

### ag-ui-protocol/ag-ui

事件/状态协议连接 agent 与 UI；按版本处理 snapshot/delta、顺序及 conformance，协议本身不执行业务或鉴权。

AG-UI: the Agent-User Interaction Protocol. Bring Agents into Frontend Applications.

### agentskills/agentskills

SKILL.md frontmatter 与渐进披露规范；可移植目录不意味着宿主支持所有扩展字段和依赖。

Specification and documentation for Agent Skills

### continuedev/continue

README 标停止维护/只读；permissions 文档提示 headless 与 TUI 默认不同，应显式策略而非借用默认。

open-source coding agent

### RooCodeInc/Roo-Code

CLI 从 ask/say 消息区分等待、完成、可恢复与输出；checkpoint 与执行状态分开，不能把部分流当终态。

Roo Code gives you a whole dev team of AI agents in your code editor.

### opencode-ai/opencode

已归档的 Go/Bubble Tea 产品，指向 Crush；权限服务与 session approval 是历史设计参考，非 anomalyco OpenCode。

A powerful AI coding agent. Built for the terminal.

### openai/openai-chatkit-advanced-samples

FastAPI + React 示例，widget action 与服务端业务状态结合；示例 store/账号流程需要生产实现替换。

Starter app to build with OpenAI ChatKit SDK

### converge-ai-labs/agent-foundation

Harness 定义与 fresh RunBindings、状态恢复分开；Service 提供平台边界，UI 不等于 HTTP SDK；总树预算由宿主聚合。

a13n - An open-source library and self-hosted platform for building and running your own agent systems—with managed agents, memory, sandboxes, computer use, and durable execution. Commercial Friendly. Built With Love 💜 @converge-ai-labs.
